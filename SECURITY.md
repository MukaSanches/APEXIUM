# Security policy

This project is an alpha source release. Do not assume production security certification.

Do not publish security vulnerabilities, API tokens or private datasets in public issues.

For a suspected vulnerability, use GitHub's private vulnerability reporting if enabled for the repository, or contact the repository owner through a private channel. Never paste credentials in a report.

Scope includes input validation, arbitrary URL/path injection, unsafe cache behavior, dependency exposure and secret disclosure. Security patches should include a regression test whenever safe to share.

APEXIUM is a client-side SDK and does not request, store or sell user identity information. External API queries still go directly to those providers and are governed by their policies.
