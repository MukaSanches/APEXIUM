# Novidades do APEXIUM Studio

## 1.1.0 (código-fonte / candidato a publicação)

- Site/app instalável (PWA) com layout responsivo e navegação desktop/mobile.
- Painel de temporada e classificações da Jolpica.
- Calendário de GPs com pesquisa e horários locais.
- Race Lab com 20 ferramentas de análise descritiva a partir de dados OpenF1.
- Telemetry Studio com gráficos da volta selecionada (velocidade, acelerador, freio e RPM).
- Explorador de endpoints OpenF1/Jolpica com exportação CSV/JSON.
- Persistência de shell offline e ícones de aplicativo.
- Testes unitários web e smoke de navegador com fixture.
- Build reprodutível e workflow preparado para GitHub Pages.

**Estado de implantação:** o site só estará público após Pages estar habilitado e o workflow de publicação passar; o código-fonte no GitHub não equivale a implantação pública.
