# Changelog

## 1.0.0 — source alpha (2026-11-06)

- Python data client with OpenF1 and Jolpica adapters.
- SQLite TTL cache, HTTP error handling and retries.
- Dataset provenance, JSON/CSV/optional Parquet export.
- High-level race selection, 20 descriptive analytics and CLI.
- Optional FastF1 integration.
- JavaScript ESM SDK with native fetch and source-specific queries.
- Offline unit tests and GitHub CI workflows.
- Documentation in English and Portuguese.

**No registries have been published and no historical download/adoption records are claimed.**
